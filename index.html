Selected work

  1. 01 harmonium Encrypted voice smuggled through an ordinary Discord call — Codec 2, WireGuard, then a homemade OFDM audio modem. Discord only ever hears modem noise. rust · dsp · wireguard
  2. 02 roomsense Room occupancy from BLE + mmWave radar fusion. Counts people and device types, never identities. Four $70 ESP32 nodes, 93.8% cross-validated. python · esp32 · ml
  3. 03 ai-pentest-suite Autonomous IoT pentest agent in a Kali container with MCP-wrapped tools. Found 30+ vulns on two routers — pre-auth RCE, heap overflows, UART root shells. python · docker · mcp
  4. 04 esp32-wg-client A WireGuard client for the ESP32, in Rust. Bare-metal crypto on a microcontroller with 4 MB of flash. rust · embedded
  5. 05 DNS-client A DNS resolver written from scratch in C. Raw query packets over UDP, response parsed by hand. No libraries — just sockets and RFC 1035. c · udp
  6. 06 thug-ring A workshop I built for my team on UDP hole punching: nodes find their public endpoints, punch through NAT, and pass messages around a ring. No server. python · nat-traversal
  7. 07 cellular-location An Android app that locates you from cell towers, no GPS. Reads CID / LAC / MCC / MNC and trilaterates from signal strength. kotlin · compose
  8. 08 plane-detection-sandbox RANSAC vs SVD vs weighted SVD vs IRLS for fitting planes to noisy 3D point clouds — a bench for how each one handles outliers on real LiDAR scans. python · numpy
  9. 09 seismic-first-break-picking STA/LTA phase picking — detecting P-wave arrivals in seismograph traces with short/long-term average ratios. python · signal-processing
